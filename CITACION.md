# Cómo citar Concordante
*Jorge Rosales Pérez · Concordante*

Cuando se haga referencia a este repositorio como presentación general del proyecto, puede usarse:

> Rosales Pérez, Jorge. (2026). *Concordante: programa independiente de investigación* [Sitio de presentación pública]. GitHub: https://github.com/XorchiPP/Concordante-

Esta referencia cita la **presentación del proyecto**, no un artículo académico específico ni sus resultados particulares.

Para trabajos científicos se debe citar por separado la versión pública correspondiente, sus autores y el DOI o identificador de publicación cuando exista.
