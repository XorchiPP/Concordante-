# Concordante

**Geometría · Información · Sistemas · Experiencia**

Un programa independiente de investigación de **Jorge Rosales Pérez**, orientado a comprender cómo las relaciones, las simetrías, las distinciones y las transformaciones permiten explicar estructuras complejas.

La pregunta guía es sencilla: **¿cuál es el corazón de una estructura presente y qué mecanismos generan las posibilidades que observamos?**

Concordante desarrolla esa pregunta desde las matemáticas, la física teórica, la computación, la ontología y la psicología. **SOURCE** es el nombre de su marco formal de trabajo; cada realización concreta conserva sus propios objetos, hipótesis y criterios de prueba.

## Cómo está organizada la biblioteca

**Exploración:** ideas, preguntas y puentes en desarrollo. **Resultado:** un enunciado delimitado con prueba o certificado del alcance declarado. **Publicación:** una versión efectivamente liberada y citable. Una misma línea puede contener resultados de diferentes estados.

La biblioteca está escrita para lectores curiosos, investigadores y revisores. Se puede recorrer sin conocer el archivo técnico interno.
