# Método y estados

Concordante combina exploración, formalización, cálculo, pruebas y revisión. Su criterio de lectura es **qué se afirma, sobre cuál objeto, con qué procedimiento y dentro de qué alcance**.

## Estados de un resultado

| Estado         | Qué significa                                                             |
| -------------- | ------------------------------------------------------------------------- |
| **Demostrado** | Existe una demostración del enunciado bajo hipótesis explícitas.          |
| **Computado**  | Un cálculo o enumeración se completó para el dominio declarado.           |
| **Hipótesis**  | Se propone un mecanismo, una relación o una consecuencia contrastable.    |
| **Refutado**   | Hay prueba negativa o contraejemplo para la afirmación precisa.           |
| **Abierto**    | La pregunta permanece sin resolución suficiente bajo el contrato vigente. |
| **Bloqueado**  | Una dependencia identificada impide la siguiente inferencia o ejecución.  |

## Del hallazgo al resultado

1. **Objeto y contrato.** Fijar dominio, operaciones, hipótesis, versiones y criterios de aceptación.
2. **Pregunta y alternativas.** Declarar qué mecanismo o propiedad se busca y qué resultados rivales son posibles.
3. **Predicción o enunciado.** Formular una consecuencia que pueda verificarse o refutarse.
4. **Prueba o experimento.** Usar demostración, cálculo exacto, enumeración, observación o intervención según corresponda.
5. **Controles.** Incluir casos negativos, perturbaciones, verificadores independientes y límites.
6. **Trazabilidad.** Registrar procedencia, evidencia, versión y decisiones editoriales.

## Tres categorías de conexión

* **SRC (fuente):** identifica de dónde procede un texto, objeto o dato.
* **DER (derivación):** especifica una consecuencia matemática de hipótesis y operaciones definidas.
* **BRIDGE (puente):** propone o demuestra una traducción entre objetos, dominios o interpretaciones, con condiciones de correspondencia.

Por ejemplo, una relación matemática exacta puede ser punto de partida de un modelo físico; su interpretación como fenómeno medible necesita su propio experimento.

## Investigación causal

Una causa se investiga mediante el mecanismo y el contraste entre condiciones. Si una intervención sobre A produce consecuencias distintas en Y bajo un modelo fijado, se puede investigar el alcance de ese efecto. **La necesidad universal y la causalidad contextual son preguntas diferentes**, ambas legítimas.

## Estados documentales

Preservar, incorporar, canonizar, activar y publicar son decisiones distintas. Un SHA-256 permite identificar los bytes de un archivo; la validez de una prueba depende de sus argumentos o verificaciones, y la publicación depende de una decisión editorial.
